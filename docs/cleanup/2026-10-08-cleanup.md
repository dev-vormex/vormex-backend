# Additional dead-code cleanup — 8 October 2026

This pass starts from the existing working tree, including the earlier cleanup described in `dead-code-audit.md`.

## Changes

- Removed unreferenced exported helpers and types for outbox batching, activity summaries, database wrappers, realtime emission, legacy JWT/cursor aliases, error wrappers, and obsolete direct-storage upload handling.
- Removed unused Bunny Stream/image helpers, unscheduled engagement jobs, unused notification methods, and unused push methods. Active worker and scheduler entry points retain their implementations.
- Removed unused controller values and an unused `userStats` database read in `getTrendingStatus`. The response never consumed that query result.
- Preserved the awaited typing-race update while dropping its unused return value. Retained `timeSpent` in the quiz-result handler that persists it.
- Removed unused imports, simplified map iteration, and marked intentionally unused Express parameters with an underscore.
- Enabled `noUnusedLocals` and `noUnusedParameters` in the TypeScript configuration. Existing `@ts-nocheck` directives remain; an additional compiler analysis ignoring those directives also found no unused locals or parameters after cleanup.

No route removals, dependency changes, schema changes, or migrations were made in this pass. All source modules remain reachable from API/process entry points, operational scripts, or tests.
